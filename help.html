Ownership claims

“This might be mine” does not mean automatic approval.

Claimants provide details that are not visible in the public listing. A moderator compares those answers with the finder’s withheld information before a claim is verified.

Frequently asked questions

Quick answers

Can I report an item without an ACT account? +

Yes. Guests can submit Lost and Found reports. You will receive a Reference ID and Guest Access Code for tracking.

Why did my report get flagged? +

The prototype uses rule-based screening. A report may be held for review if it contains spam-like wording, public contact information, unsafe content, an invalid future date, a very short description, or a possible duplicate.

Does automatic moderation prove a report is true? +

No. Automatic moderation only checks whether a submission appears complete and safe enough to publish. Ownership is handled separately through claim verification.

I am a guest. How do I get back to the return chat? +

Open Guest Tracking and use your Reference ID plus Guest Access Code. If Return Coordination is already open, you will see an “Open return chat” button. On the same browser, a Recent Guest Cases shortcut may also appear.

Why should I log in if guests can use the system? +

Registered users get My Reports, My Claims, notifications, easier status tracking, and direct access to secure return coordination from My Account.

What information should never be posted publicly? +

Do not post passwords, PINs, OTPs, unlock codes, banking information, full serial numbers, or detailed proof-of-ownership information in public descriptions.

When is an item marked Returned? +

The system marks a return complete after the owner and finder both confirm the handoff, or when an ACT moderator confirms an ACT-managed return.
