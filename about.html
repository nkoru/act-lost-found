About the system

Helping the ACT community trace, verify, and return lost belongings.

ACT Lost & Found is designed for students, staff, visitors, and other members of the ACT community. It makes it easier to report missing or found items, discover possible matches, verify ownership, and coordinate a safer return.

Browse reports How the system works

Open access

Guests can participate

Visitors do not need an ACT account just to report or help return an item.

Safer claims

Ownership is verified

Private identifying details are withheld from public listings and used during claim review.

Moderation

Normal reports can publish without waiting for an admin

Automatic rule-based screening publishes normal submissions and holds suspicious ones for moderator review.

What the system is for

Less searching. More recovering.

ACT Lost & Found keeps the recovery process focused on one goal: reconnecting belongings with the right person without turning the platform into another social feed.

Designed around recovery

No public comments. No likes. No unnecessary personal information. Just reporting, matching, verification, and return coordination.

How it works

From report to successful return.

Each item moves through a clear recovery path designed to keep public information useful and private information protected.

01

Report

Submit useful details about the missing or found item.

02

Screen

Normal submissions publish after rule-based validation while suspicious ones are held for review.

03

Match

Compare item details, category, color, location, and date.

04

Verify

Ownership proof is checked against private identifying details.

✓

Return

Secure coordination and handoff confirmation close the case.

Who can use it

One system. Three ways to participate.

Account access changes how activity is tracked—not whether someone is allowed to help recover an item.

Guest / Public

Help without creating an account.

Guests can participate immediately and use secure case credentials to come back later.

✓ Browse and search reports

✓ Report lost or found items

✓ Submit ownership claims

✓ Submit return leads

Guest cases receive a Reference ID and 6-digit Guest Access Code.
Registered ACT User

Everything organized in one account.

Registered users get a personal dashboard for ongoing reports, claims, notifications, and return cases.

✓ My Reports and My Claims

✓ Status notifications

✓ Return activity

✓ Secure coordination access

Signing in adds convenience—it does not block guests from helping recover an item.
Admin / Moderator

Protect the recovery process.

Moderators step in where verification, suspicious content, or return supervision needs human review.

✓ Review flagged reports

✓ Verify ownership claims

✓ Review return leads

✓ Supervise completed returns

Moderators can view private verification information that never appears on public report pages.
